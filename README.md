# FileBackupRestoreApp

A C# application for backing up and restoring files with ease.

## Features

- **File Backup**: Create backups of important files and directories
- **File Restore**: Restore files from existing backups
- **Simple Interface**: User-friendly application for managing backups

## Getting Started

### Prerequisites

- .NET Framework or .NET Core
- Windows operating system (for desktop application)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/liewvk/FileBackupRestoreApp.git
   cd FileBackupRestoreApp
   ```

2. Build the project:
   ```bash
   dotnet build
   ```

3. Run the application:
   ```bash
   dotnet run
   ```

## Usage

1. Launch the application
2. Select files or directories to backup
3. Choose a backup location
4. Click "Backup" to create a backup
5. To restore, select the backup and click "Restore"
